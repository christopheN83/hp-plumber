# HP-Plumber

A Mario-style platformer for the **HP Prime** graphing calculator, written entirely in **PPL** (HP Prime Programming Language).

## Features
- 5 playable levels with increasing difficulty
- Enemies (Goombas, Koopas), blocks, pipes, coins, and power-ups
- Procedurally generated levels beyond level 3
- Multi-language UI: French, English, Spanish
- Pixel-art rendering, parallax backgrounds, animated sprites
- Built-in help screen and pause menu

## Installation
1. Download `hp-plumber.hpprgm` from the `src/` folder.
2. Open **HP Connectivity Kit** and connect your HP Prime.
3. Drag the `.hpprgm` file onto your calculator.
4. On the calculator, press `Apps` and launch **HP-Plumber**.

## Controls
- `7` / `8` : move left / right
- `2` or `ENTER` : jump
- `4` : pause / quit
- `3` : help

## Project structure
- `src/` — the `.hpprgm` file for direct installation
- `plaintext/` — plain text version of the source for browsing on GitHub
